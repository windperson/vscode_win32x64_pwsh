# .NET 10 SDK portable folder

This folder contains the [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) binary distribution files, so the User computer can use it without installation.

Be sure to download the .NET 10 SDK x64 zip file from the official site and extract the content to this folder, and add this folder's absolute path to the `PATH` environment variable (either User Level or System Level) so we can use this .NET 10 SDK tools in VSCode and also its integrated terminal.
